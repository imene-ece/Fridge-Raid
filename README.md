# Fridge-Raid
Site vitrine de FRIDGE RAID, une marque fictive de snacks anti-gaspillage.

## Présentation
FRIDGE RAID est une marque fictive de snacks anti-gaspillage qui transforme les fruits et légumes imparfaits ou invendus en produits gourmands.

## Membres du projet
- Imene Aitzouaoui
- Rooney Plazas Betancourt
- maurine

## Objectif
Créer un site vitrine pour présenter la marque, ses produits et son engagement contre le gaspillage alimentaire.
